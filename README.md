## 🌐 Deploy to GitHub Pages

To view this portfolio live on GitHub Pages:
1. Go to **Settings** > **Pages** in this GitHub repository.
2. Select **Source**: `Deploy from a branch`.
3. Select **Branch**: `main` (or `master`) / `(root)` and click **Save**.
4. Your website will be live at: `https://GopikrishnaAR.github.io/Graphic-designer-portfolio/`
